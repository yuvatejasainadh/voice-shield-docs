# FAQ

## What is Voice Shield?
An AI-assisted voice authenticity risk-analysis system for detecting potential impersonation/deepfake speech.

## Is detection real-time?
Current production code is request/file-based. Continuous chunk streaming is planned.

## Does Voice Shield record calls?
Android workflow can analyze discovered call recordings when user/device provides access and settings allow it.

## What does risk score mean?
A 0-100 score derived from provider output and classification mapping.

## Can it detect every deepfake?
No. Detection is probabilistic and has known false-positive/false-negative limits.

## Where is API hosted?
App defaults point to `https://voice-api.asteriontechnologies.tech/`.

## Where to download APK?
Web project includes an APK download page, but URL configuration may be placeholder depending on deployment config.
