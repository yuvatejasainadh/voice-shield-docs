# Glossary

- **Voice cloning**: synthetic imitation of a real speaker's voice
- **Deepfake audio**: AI-generated or manipulated speech intended to appear real
- **Spoof audio**: deceptive synthetic/manipulated voice sample
- **Genuine audio**: expected natural human voice sample
- **Chunk**: short segment of a longer call/audio stream
- **Sliding window**: overlapping fixed-length chunking strategy for analysis
- **Inference**: model/provider prediction step
- **Confidence**: certainty estimate associated with prediction
- **Risk score**: normalized 0-100 risk value
- **Risk level**: mapped severity bucket from score/classification
- **Call session**: one logical call lifecycle instance
- **Webhook**: server-to-server callback mechanism
- **FastAPI**: Python web framework used by backend
- **WavLM**: pretrained speech representation model family used in benchmark experiments
- **ASR**: automatic speech recognition
- **TTS**: text-to-speech synthesis
- **Speaker embedding**: vector representation of speaker identity characteristics
