# Android Permissions

From `AndroidManifest.xml`:
- `INTERNET` — backend communication
- `RECORD_AUDIO` — microphone capture
- `POST_NOTIFICATIONS` — risk/completion alerts
- `VIBRATE` — notification vibration
- `READ_PHONE_STATE` — call state monitoring
- `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` — recording discovery
